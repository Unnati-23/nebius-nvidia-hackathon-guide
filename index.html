01

RL Environment for AI Agents

Track: Coding & Agentic Engineering

A training gym for coding agents: give an agent a broken repo, let it write and run code in a sandbox, and score it automatically with real tests.

Why this can win

Everyone is building agents. Very few people are building the place where agents get better. Reinforcement learning environments are how frontier labs train coding agents, so an open, reusable one built on Nemotron is a non-obvious idea that judges in this track will immediately understand.

How it works

Task (buggy repo) → Agent (Nemotron) → writes code → Sandbox runs it → Tests = reward → Leaderboard + trajectories

Tech stack

Nemotron Nano / Super (agent)Nemotron 3 Ultra (judge)Nebius Token FactoryNebius Serverless JobsPythonGymnasium-style APIDocker sandboxpytest

Build steps

  1. Create the task setCollect 20–50 small Python tasks, each with a bug and a hidden test file. Store them as JSON: repo files, task description, tests.
  2. Write the environmentBuild a Gymnasium-style class with reset() (load a task) and step(action) (agent edits a file or runs a command). Every action executes inside an isolated Docker container.
  3. Define the rewardReward = percentage of tests passed. Add small penalties for extra steps and for breaking tests that were already passing, so agents learn to be efficient.
  4. Plug in the agentCall Nemotron through the Token Factory API as the policy. Use Nemotron 3 Ultra as an optional judge that scores code quality on top of test results.
  5. Scale with Serverless JobsRun many episodes in parallel on Nebius Serverless Jobs and save every trajectory (prompt, action, output, reward) to JSONL.
  6. Build the dashboardShow a leaderboard comparing models (Nano vs Super vs Ultra), pass rates per task, and a replay viewer for any episode.

Make it stand out: Export the saved trajectories as a ready-to-use training dataset. Now your environment doesn't just test agents, it produces the data to improve them.

Demo video plan (under 3 minutes)

  • Show one task: the broken code and the failing tests.
  • Watch the agent attempt it live, step by step, in the replay viewer.
  • Show the reward and the leaderboard across three Nemotron models.
02

Private Assistant With Persistent Memory

Track: Personal AI

An always-on personal assistant that remembers you across every conversation, learns reusable skills, and keeps all your data under your control.

Why this can win

This is almost word-for-word what the Personal AI track asks for: persistent memory, reusable skills, access to tools you choose, and tasks across your daily workflow. The winning angle is privacy you can see, so build a memory panel where the user can view, edit and delete everything the assistant knows.

How it works

You → Assistant (Nemotron) → recalls from Memory store → uses Skills + Tools → acts → saves new memories

Tech stack

Nemotron on Token FactoryNVIDIA NemoClawOpenShellHermes AgentNebius ServerlessSQLite + vector indexTelegram or web chat UI

NemoClaw, OpenShell, Hermes Agent and Nebius Serverless are the tools the track itself suggests for assembling, securing and running your assistant.

Build steps

  1. Design the memory layersThree types: facts (name, preferences), episodes (summaries of past chats), and skills (saved workflows like "plan my week"). Store them locally, encrypted.
  2. Write and retrieve memoriesAfter each chat, have Nemotron extract new facts and a short summary. Before each reply, retrieve the most relevant memories with vector search and add them to the prompt.
  3. Add skillsLet the user say "save this as a skill." Store the steps as a reusable recipe the assistant can run again on command.
  4. Connect toolsGive it access only to what the user chooses: calendar, notes, email, files. Run tool calls inside a sandboxed shell so nothing touches the system unchecked.
  5. Make it always-onDeploy on Nebius Serverless so it runs scheduled tasks, like a morning brief or a reminder, without you opening the app.
  6. Build the memory panelA simple page listing every stored memory, with edit and delete buttons. This is your privacy proof for the judges.

Make it stand out: Use Nemotron Nano for fast everyday replies and route only complex planning to Nemotron 3 Ultra. Show this routing in the demo, since the track rewards apps that stay responsive and stretch credits.

Demo video plan (under 3 minutes)

  • First chat: tell it a few things about yourself and save a skill.
  • New session: it remembers you and runs the saved skill on command.
  • Open the memory panel, delete a memory, and show it's truly forgotten.
03

Workflow That Generates Training Data

Track: Best Apps & Agents

Type a topic, get a clean, high-quality dataset ready for fine-tuning: generated, checked and filtered by Nemotron, end to end.

Why this can win

Good training data is the bottleneck for every team fine-tuning a model. A workflow that runs itself and produces usable datasets is a real product for a real audience, and it's eligible for the $3,000 Best Use of Tavily bonus if you pull fresh web sources with Tavily.

How it works

Topic → Tavily finds sources → Nemotron Super generates Q&A pairs → Nemotron 3 Ultra grades + filters → dedupe → JSONL export

Tech stack

Nemotron Super (generator)Nemotron 3 Ultra (grader)Nebius Token FactoryNebius Serverless JobsTavily Search APIPythonHugging Face Datasets

Build steps

  1. Collect seed sourcesThe user enters a topic (e.g. "Indian tax law for freelancers"). Tavily searches the web and returns fresh, relevant pages as grounding material.
  2. Generate examplesNemotron Super turns each source into instruction–response pairs in the format the user picks: Q&A, chat, or reasoning with step-by-step answers.
  3. Grade and filterNemotron 3 Ultra scores every example for accuracy against the source, helpfulness and clarity. Anything below the threshold is dropped or rewritten.
  4. Clean the datasetRemove near-duplicates, balance difficulty levels, and keep the source link on every example so it's traceable.
  5. Run at scaleMove generation to Nebius Serverless Jobs so a 1,000-example dataset builds in the background while the user watches progress.
  6. ExportDownload as JSONL or push straight to Hugging Face, with a quality report showing scores and topic coverage.

Make it stand out: Close the loop. Fine-tune a small model on the generated dataset and show a before vs after answer in your demo. That proves the data actually works.

Demo video plan (under 3 minutes)

  • Enter a topic and watch Tavily pull sources live.
  • Show generated examples, with rejected ones and their low scores.
  • Export the dataset and show the quality report.
